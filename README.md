# Wawawi

Заглушка сайта Wawawi — сервиса, который за минуту помогает решить, что съесть сегодня из продуктов, которые уже есть дома. На странице можно погладить и покормить котёнка-поваренка, получить карточку блюда с рецептом и прочитать о проекте.

#### Запись №1 

- **Какой был план:** заглушку сайта в стиле проекта: обложку, информацию о проекте, без кнопки «Начать», потому что начинать пока нечего.
- **Какой был запрос:** «Сможешь сделать веб-страницу в похожем стиле? Заглушка сайта…», потом «Ну там должна быть какая-то информация о проекте + кнопку начать надо убрать».
- **Что ответил ИИ:** сделал страницу из одного HTML-файла с обложкой и раскрывающимся блоком «О проекте»: «Что это», «Для кого», «Боль аудитории», «Исследование», «Как это будет работать».
- **Где была приложена рука:** код правился самостоятельно чтобы подчистить какие-то ИИ артефакты. Например,убрать блики, сделать элементы квадратными, убрать плашки «сайт готовится» и блок «Что дальше». Анализ полученной структуры кода.Дала данные из исследования (интервью с аудиторией и Job Stories).
- **Проверка на неисправности:** открывала страницу в браузере, проверяла на компьютере и телефоне.прогонка через VS код.

#### Запись №2 

- **Цель:** интерактив с котёнком-поваренком между обложкой и блоком о проекте.
- **Какой был запрос** «Добавь между двумя блоками блок с интерактивом котенка-поваренка», затем выбрала варианты «погладить и покормить».
- **Что ответил ИИ:** написал кухню на JavaScript: котёнка гладят с зажатой кнопкой мыши, продукты перетаскивают на него, он подсказывает блюдо и спрашивает «Это всё или добавишь ещё?».
- **Где была приложена рука:** код сама не правила. Попросила, чтобы продукты засчитывались только при перетаскивании, чтобы гладить можно было только с зажатой кнопкой, чтобы диалог был под котёнком и чтобы продукты не «зависали».
- **Проверка на неисправности:** Проверка интерктива - гладила и кормила котёнка на компьютере и телефоне.

#### Запись №3 

- **Идея:** карточку блюда в стиле покемонов с рецептом на обороте и больше рецептов.
- **Запрос:** «…на карточку можно было нажимать… рецепт… картинки именно готовых блюд… расширь варианты рецептов».
- **Что ответил ИИ:** сделал карточки, которые собираются кодом из данных рецепта, с рисунком готового блюда, кнопками «Беру!» и «Другое» и свайпом. 
- **Где была приложена рука:** код сама не правила.Правила только изображние карточек. Сделала так, чтобы карточка стояла сбоку от котёнка и котёнок не пропадал при перевороте.
- **Как я поняла, что это работает:** собирала разные наборы продуктов и смотрела, какие блюда выпадают, переворачивала карточку.

Что вы теперь умеем делать сами, без ИИ — честно своими словами.
• Работали с файлами проекта безопасно: делали копию для тестов.
• Редактировали нужное место в коде в VS Code (например, строку answerArea.append(label,ta);) и вставляли и редактировали этот туда кусок код.
• Публиковали изменения на GitHub через веб-редактор.
• Подключили бота через BotFather к странице на GitHub Pages как Mini App с кнопкой «Пройти опрос».
• Настроили Google-таблицу: удалили тестовые ответы и открыли доступ по ссылке.
• Тестировали сайт как пользователь: находили ошибки и точно описывали, что не так. Это тоже навык, на нём держится вся отладка.
• Изучили архитектуру таких сайтов. Например,выяснили и закрепили,что сайт — это HTML (структура), CSS (внешний вид) и JavaScript (поведение).
• Цвета удобно хранить в переменных: поменял в одном месте, и перекрасился весь сайт.
• Данные можно отделить от вёрстки: Например,82 рецепта лежат списком, а карточки собираются из него автоматически.
• Адаптив: на узком экране страница перестраивается в одну колонку.
• Резервная копия перед каждым изменением спасает работающую версию.
